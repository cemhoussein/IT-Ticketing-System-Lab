# IT Ticketing System Lab

## Project Overview

Created a simulated IT service desk environment using Spiceworks Cloud Help Desk to gain practical experience with ticket management and IT support workflows.

The project involved creating and managing support tickets, assigning priorities and categories, communicating through ticket comments, tracking ticket status changes and documenting an escalation.

## Tools Used
- Spiceworks Cloud Help Desk

## Support Scenarios

### 1. Wi-Fi Connectivity Issue
- Created a ticket for a user experiencing office Wi-Fi connectivity issues.
- Identified an expired Wi-Fi certificate within the simulated scenario.
- Documented the certificate renewal and requested the user to test connectivity.
- Recorded the user's confirmation that the connection was working.
- Closed the ticket following confirmation.

### 2. Database Access Request
- Created a ticket for a user requesting access to a financial database.
- Recorded the user's account details and access request.
- Added an escalation comment requesting review by the relevant database team.
- Kept the ticket open pending further review.

### 3. Company Email Access
- Created and prioritised a high-priority ticket concerning access to a company email account.
- Managed the request through the Spiceworks ticketing system.

## Additional Ticket Management
- Assigned tickets to a technician.
- Applied priority levels including Low, Medium and High.
- Used categories such as Network, Email and Other.
- Managed open and closed ticket statuses.
- Reviewed ticket history to track status changes.
- Used comments to document communication and updates.

## Skills Developed
- IT service desk ticket management
- Incident logging and prioritisation
- Ticket categorisation
- User communication
- Escalation procedures
- Ticket lifecycle management
- Support documentation
